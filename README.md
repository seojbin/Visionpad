닷듀밸리 - 요리 / 마을 / 상점 / 음식

1. 주요 변경
- 집에 주방 오브젝트 추가
- 현재 가진 작물로 만들 수 있는 레시피만 표시
- 레시피 선택 -> 필요한 재료 직접 선택 -> 조리 시작
- 요리별 서로 다른 점자 선 경로를 표시
- 시작점에서 누른 채 선을 순서대로 따라가면 성공
- 조리 미니게임에는 제한시간과 대성공 판정 없음
- 실패해도 재료를 소비하지 않고 다시 시도 가능
- 완성한 요리는 F3 인벤토리에서 사용 가능
- 모든 음식은 일정 시간틱 동안 수확량 +25% 버프 제공
- 버프는 행동 시간틱이 소비될 때 감소
- 수확 판정 시 남은 버프가 있으면 최종 수확량에 곱해짐

2. 마을/미니맵
- F1 미니맵: 집, 농장, 마을 표시
- 집에 농장 출구와 마을 출구가 각각 존재
- 마을에는 상점 NPC가 존재
- 장소 hover TTS는 장소명을 먼저 읽고 방향을 뒤에 읽음

3. 상점
- 상점 NPC 선택 -> 화면 왼쪽 전체는 판매, 오른쪽 전체는 구매
- 판매: 보유 작물과 완성 요리를 1개씩 판매
- 구매: 토마토/당근/감자 씨앗과 비료를 1개씩 구매
- 골드는 F3 인벤토리에서 확인 가능

4. 기본 가격
- 당근 작물 10 / 씨앗 8
- 토마토 작물 12 / 씨앗 10
- 감자 작물 15 / 씨앗 12
- 비료 12
- 씨앗은 작물 가격보다 약 20% 저렴하도록 설정
- 요리는 사용 재료의 작물 판매가 합계 x 1.2를 올림하여 판매가 계산
  토마토 당근 스튜: 27
  감자 토마토 수프: 33
  정원 채소 스튜: 45

5. 요리 레시피
- 토마토 당근 스튜: 토마토1 + 당근1, 버프 6틱
- 감자 토마토 수프: 감자1 + 토마토1, 버프 7틱
- 정원 채소 스튜: 토마토1 + 당근1 + 감자1, 버프 9틱
- 각 레시피는 game_config.json 안에 서로 다른 gesture.path를 가짐
- gesture.tolerance 기본 4.5로 넉넉하게 설정

6. 기존 기능 유지
- 농장 초기 밭 2개
- 연구 상자에서 씨앗 반환 확률/밭 확장
- 물뿌리개와 비료 drag
- 작물은 수면 후 다음 날에만 성장
- 밭 아래 성장 진행도 표시
- 확대 수확 drag 미니게임
- 하단 별도 40x4 행동 시간 패널
- 시간이 끝나면 자동으로 집으로 이동하고 침대만 사용 가능

7. 실행
pip install -r requirements.txt
uvicorn game_app:app --host 127.0.0.1 --port 8003
브라우저에서 http://127.0.0.1:8003

8. Hand Tracking 연결
hover/move -> /api/pointer/move
pinch down -> /api/pointer/down
pinch drag -> /api/pointer/drag
release -> /api/pointer/up

요리와 수확은 모두 같은 drag API를 사용하므로 카메라 입력을 위해 별도 게임 로직을 만들 필요가 없음.
