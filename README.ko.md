# Dotdew Valley

[English](README.md) | 한국어

60×40 촉각 디스플레이인 Dot Pad용 농사·생활 시뮬레이션 게임이다. 시각장애인과 저시력 사용자가 촉각과 소리로 게임 세계를 읽고, 읽고 있는 바로 그 화면에서 직접 행동한다. 집, 농장, 마을, 광산, 낚시 호수를 오가며 농사, 요리, 채굴, 낚시, 거래, 연구를 한다. 도형과 영어 음성이 안내하며 점자를 몰라도 된다.

브라우저 시뮬레이터는 마우스와 키보드를 지원한다. USB 또는 블루투스 Dot Pad와 외부 손 추적 카메라를 연결할 수 있고, 별도의 Visual Companion 창이 같은 게임을 이미지로 보여주며 함께하는 일반인이 볼 수 있고 게임을 즐길 수 있다.

## 기획

Stardew Valley의 농사·생활 활동을 촉각으로 탐색하고 수행할 수 있도록 구성한 게임이다. 오브젝트를 찾고, 음성으로 확인하고, 같은 공간에서 직접 활동한다. 시각화 창 없이도 촉각 게임을 플레이할 수 있다.

| 구분 | 용도 |
|---|---|
| 촉각 | 위치, 형태, 이동 경로, 성장과 활동 진행 상태 |
| 음성·효과음 | 이름, 수량, 행동 결과와 방향 안내 |
| Visual Companion | 저시력 사용자와 동행자를 위한 이미지, 큰 수량 표시와 선택 강조 |
| 버튼 | 이동, 메뉴, 선택, 저장·로드 |
| 포인터·손 추적 | 탐색, 목표 쓸기, 경로 따라가기, 오브젝트 선택 |

농사·요리·채굴·낚시·거래·연구·Rowan의 튜토리얼 퀘스트·화초 기르기가 구현되어 있다. 목축·펫·음악·제작·추가 NPC는 확장 예정 및 관련 이미지 제작 완료하였다.

## 설치

Python 3.11 이상을 설치한 뒤(3.12 64비트 권장. Windows 설치 파일은 3.12가 있으면 그것을 쓴다) **install-windows.bat**(Windows) 또는 **install-mac.command**(macOS)를 한 번 연다. 프로젝트 안에 `.venv/`를 만들고 `engine/requirements.txt`를 설치하며 영어 음성 두 개를 `.audio/voices/`에 내려받는다. 내려받은 파일은 크기와 SHA-256으로 확인하며, 끊기거나 손상된 파일은 다시 받는다(오류가 나면 설치 파일을 다시 실행한다). 전역 Python에는 아무것도 설치하지 않는다. 이 단계에는 인터넷이 필요하며 계정이나 API 키는 쓰지 않는다. 블루투스 Dot Pad를 쓰려면 설치 파일을 `--with-pad`와 함께 실행해(예: `install-windows.bat --with-pad`) Dot Inc.의 SDK도 내려받는다. 게임, USB 패드, 손 추적은 SDK 없이도 동작한다.

```
python -m venv .venv
.venv\Scripts\activate                 # macOS / Linux: source .venv/bin/activate
python -m pip install -r engine/requirements.txt
python engine/tools/prepare_speech.py --download
```

`python engine/launcher/check_setup.py --synthesize`는 게임을 시작하지 않고 패키지·파일·소리·음성을 점검한다. 설정 파일은 편집기가 BOM을 붙여 저장해도 UTF-8로 읽으며, Windows 실행 파일은 Python을 UTF-8 모드로 실행하므로 한국어(cp949) 코드 페이지와 상관없이 동작한다.

## 실행

**start-windows.bat**(http://127.0.0.1:8003) 또는 **start-mac.command**(http://127.0.0.1:8000)를 열거나 `python engine/launcher/launch_game.py --prepare-demo`(포트 8000)를 실행한다. 실행기는 설치 상태를 확인하고, 게임 서버를 새로 시작하거나 이미 켜진 서버를 재사용하며, 시연 음성을 준비하고 브라우저를 연다. 플레이하는 동안 실행 창을 열어 둔다.

1. 게임 페이지를 클릭하거나 키를 눌러 오디오를 켠다.
2. **Open visual display**를 눌러 시각화 창을 연다(팝업 허용).
3. F3를 길게 눌러 저장한다. 서버를 끄면 진행이 사라진다. 저장 파일은 `saves/`에 있다.

## 조작

| 입력 | 동작 |
|---|---|
| 올려놓기(호버) | 오브젝트 이름과 상태 듣기 |
| 클릭, Enter, F4 | 선택, 시설 사용, 돌 치기, 낚시 |
| 목표나 경로 위로 이동 | 물 주기, 비료, 수확, 요리 경로 따라가기 |
| F1 / F2 | 지도 / 인벤토리. 다시 누르면 돌아온다 |
| F3 짧게 / 길게 | 저장 목록 열기 / 새 슬롯에 저장 |
| 왼쪽·오른쪽 방향키 또는 패드 버튼 | 이동, 뒤로 가기, 페이지 넘기기 |
| W A S D | 캔버스에 포커스가 있을 때 포인터를 한 도트씩 이동 |
| Space | F4와 동일하게 포인터 위치를 한 번 선택. 입력창·버튼에 포커스가 있으면 해당 컨트롤 동작 유지 |
| Shift 누르기 상태 | tts 상세 설명 모드. 떼면 일반 이동으로 복귀 |

장소 순서는 농장 ↔ 집 ↔ 마을 ↔ 광산&호수(상하 이동)다. 장소 이동에는 시간이 들지 않는다. 일반 오브젝트에 포인터를 올리면 정보를 듣지만, 이동 기반 미니게임 안에서는 목표 위로 이동하는 것만으로 진행된다. 진행하지 않고 읽으려면 Shift를 누른다. 현재 F4는 클릭 대체 버튼이며, 제스처 대체가 가능한 경우를 대비해 기존 일시정지 경로는 코드에 남아 있다.

## 기능과 플레이 방법

### 네비게이션과 하단 표시

좌우 방향키로 **농장 ↔ 집 ↔ 마을** 순서로 이동한다. 도착하면 장소 이름을 읽고, 이동할 수 없는 방향에는 짧은 안내를 한다. F1 미니맵에서는 장소를 탐색한 뒤 선택해 이동한다. 현재 위치의 노드는 내부를 채워 구분한다. 마을의 경우 상하이동 버튼이 따로 있어 해당 디스플레이 버튼으로 **광산** 과 **호수**로 이동한다.

F1·F2 메뉴창에서 같은 키를 다시 누르면 현재 지역으로 돌아간다. 메뉴는 다른 메뉴를 거쳐도 창이 중첩되지 않는다. F1을 누르면 나오는 미니맵에서는 어느 방향키든 지역으로 복귀한다. F2를 누르면 나오는 인벤토리의 방향키는 페이지 이동 전용이며 끝에서는 첫·마지막 페이지라고 안내한다. 따라서 인벤토리는 방향키 사용이 페이지 이동이며 F2로 닫는다. F3을 누르면 나오는 세이브파일 목록은 F3 또는 뒤로가기로 직전 화면을 복원한다. 여러 페이지가 없는 메뉴 화면에서는 양쪽 방향키로 뒤로가기 역할이 가능하다. 상점에서는 이동 가능한 페이지가 있으면 페이지 전환을 우선하며, 구매·판매 첫 페이지의 왼쪽은 상점 선택 화면으로, 상점 선택 화면의 뒤로가기는 마을로 연결된다.

하단 20셀 패널은 평소 활동 시간을 표시한다. 여러 페이지가 있는 목록에서는 전체 폭을 페이지 수로 나눠 페이지 위치 막대로 바뀐다. 상점 단일 페이지에서는 뎁스 구분을 위해 **shop**, **buy**, **sell**을 점자로 표시한다. 페이지 표시는 장소 글자보다 우선하며 수면 중에는 패널을 끈다.

데모에서는 shift, 실제 실행에서는 point 제스처를 취하는 것으로 각각의 장소와 호버링 물체에 대한 상세 tts를 출력 가능하다.
### 인벤토리와 아이템 구분

F2를 눌러 소지품을 확인한다. 첫 페이지에는 골드와 사용 가능한 아이템을 두고, 음식이 많으면 음식 페이지를 먼저 정렬해 추가한다. 이후 씨앗·작물·물고기·광물·도구를 표시한다. 수량이 0인 항목은 숨기며 페이지당 최대 12개를 3행 4열로 배치한다. 음식은 선택해서 먹을 수 있고, 나머지 항목은 인벤토리에서 정보를 확인 가능하다.

현재 촉각 렌더러의 일반 아이템·골드·NPC는 한 줄 사각형 프레임을 사용한다. 음식은 내부 아이콘 없이 사각형 테두리를 두 겹으로 표시한다. 씨앗·작물·광물·도구는 프레임 안의 종류별 도형으로 구분한다. 공통 격자를 사용해 위치를 일정하게 유지한다. 시각화 창은 모든 촉각 프레임을 그대로 복제하지 않고 이미지 카드와 수량을 표시한다.

### 집, 시간과 수면

집에서는 침대를 선택해 잠들고, 연구대에서 업그레이드하며, 주방에서 요리한다. **Flower pot**은 화초 관리 화면을 연다. 새 게임은 골드 60개, 비료 2개, 작물 씨앗과 요리용 채소 각 3개로 시작한다.

시간은 활동에 소모되는 틱이다. 현재 하루 한도는 20틱이다. 심기·물·비료·돌 파괴·낚시는 각각 2틱, 수확·연구·요리는 3틱, 이동은 0틱이다. 채광은 한 번 칠 때가 아니라 돌을 완전히 부술 때 차감한다. 음식 효과에 따라 시간 비용이 달라질 수 있다.

활동 시간이 소진되면 집으로 돌아오고 침대를 선택해야 다음 날이 된다. 수면 중 촉각 패널이 2초간 꺼지고 배경음악도 멈춘다. 다음날이 되면 물을 준 작물이 자라고 화초 상태가 갱신되며 광산의 돌도 새로 생긴다. 시각화 창은 시간대와 수면 전환을 함께 표현한다.

### 농사: 심기, 물주기, 비료와 수확

1. 농장에서 밭을 선택한다. 농장 화면에서는 밭 내부가 아래부터 채워지며 성장도를 나타낸다.
2. 빈 밭에서는 심기를 고른 뒤 보유 씨앗을 선택한다. 작물이 있으면 성장·물·비료 상태를 확인한다.
3. 물주기나 비료주기를 선택하고 목표 도트 위로 손이나 포인터를 이동한다. 클릭을 유지할 필요가 없다.
4. 물을 준 뒤 잠들면 작물이 자란다. 비료는 사용 즉시 성장일을 하루 앞당기는 선택적인 성장 보조 수단이다.
5. 다 자란 밭에서 수확을 선택하고 모든 목표를 통과한다. 제한시간과 미니게임 점수에 따른 수확량 배율은 없다. 기본 수확량·음식 효과·화초 보너스로 결과를 계산하며 연구를 통해 얻는 효과인 씨앗 회수는 별도로 판정해 씨앗을 돌려준다.

물·비료 목표와 요리 경로는 접촉 후 잠시 남았다가 사라진다. 현재 지연은 200ms이며, 촉각으로 읽을 시간을 1초로 늘리려면 1000ms로 설정한다. 지연 표시를 사용하는 활동은 해당 표시가 끝난 뒤 완료 처리한다.

### 요리와 음식 효과

주방에서 요리법을 고르고 재료를 선택한다. 필요한 재료를 모두 선택하면 자동으로 조리가 시작된다. 클릭을 유지하지 않고 시작점부터 두 단계 경로를 차례로 따라간다. 진행이 멈추면 재개할 위치를 표시한다. 재료와 요리 시간은 첫 단계가 아닌 음식 완성 시에 소모하며, 제한시간은 없다.

1차 요리는 재료에 따라 바뀐다 - 생선은 가로 손질경로, 채소는 세로 썰기경로, 2차 요리는 조리법에 따라 바뀐다 - 튀김/구이/수프젓기가 구현되었다.

| 채소 요리 | 재료 — 각 1개 | 효과 | 지속시간 |
|---|---|---|---|
| Tomato carrot stew | 토마토·당근 | 수확량 증가 | 게임 시간 6시간 |
| Potato tomato soup | 감자·토마토 | 곡괭이 보호 | 게임 시간 10시간 |
| Vegetable fritters | 감자·당근 | 시간 소모 감소 | 게임 시간 10시간 |

| 생선 요리 | 채소 | 사용할 수 있는 생선 | 효과 |
|---|---|---|---|
| Grilled fish | 감자 | 고등어·잉어·연어 | 철·다이아몬드·희귀 어종 획득 확률 증가, 12 / 14 / 16시간 |
| Fish stew | 토마토 | 정어리·메기·무지개송어 | 판매가 증가, 3 / 4 / 5회 판매 |
| Fried fish | 당근 | 배스·가자미 | 확률적으로 획득량 2배, 12 / 14시간 |

생선의 경우 재료 희귀도에 따라 음식 이름 앞에 **Simple(소박한)**, **Ordinary(평범한)**, **Luxurious(호화로운)**를 붙이고 해당 레어도에 따라 효과 강도가 달라진다. 설명에는 지속시간이나 남은 판매 횟수를 표시하되 확률·배율은 직접 안내하지 않는다. F2 인벤토리에서 먹으면 적용되며, 음식 효과는 한 번에 하나만 유지된다. 다른 음식을 먹으면 교체된다. 시간형 효과는 소비한 게임 시간만큼 줄고, 판매형 효과는 판매 성공 시에만 횟수가 줄어든다.

### 채광

광산에서 돌을 선택하면 타격한다. 입장은 자유지만 돌을 치려면 곡괭이가 필요하다. 상점에서 한 개만 보유할 수 있고, 부서지면 다시 구매한다. 하루 최대 7개의 돌이 간격을 두고 생기며 기본적으로 세 번 치면 부서진다. 손상에 따라 정해진 패턴으로 내부 도트가 줄지만 외곽은 유지해 위치와 크기를 읽을 수 있다.
곡괭이는 9회 타격 이후부터 파괴 확률이 5퍼센트씩 점진적으로 증가한다.

돌을 부술 때마다 정해진 확률에 따라 돌·구리·철·다이아몬드를 얻으며 연구와 음식이 결과를 개선할 수 있다. 타격, 바위 파괴, 레어템 획득,도구 파괴에 서로 다른 소리를 사용한다. 도구가 파괴되는 타격에서는 일반 타격·바위 파괴음 대신 도구 파괴음을 재생한다. 내구도와 획득 확률은 공개하지 않는다.

### 낚시

광산 옆에 낚시 호수가 있다. 장비 없이 입장할 수 있지만 낚시에는 낚싯대가 필요하다. 기본 가격은 100골드이며 한 개만 보유한다. 스테레오 헤드폰을 사용하고 반복되는 물소리를 따라 포인터를 움직인다. 물소리는 포인터를 기준으로 목표 방향에서 들리며 가까울수록 커진다. 촉각 테두리가 호수 범위를 나타내고, 시각화에는 명중 구역을 공개하지 않는다. 목표 지점에 가까울수록 꽝 확률이 줄어들고 희귀 어종 획득 확률이 상승한다.

호수 안에서 클릭·Enter·F4를 누르면 물고기를 낚는다. 성공과 꽝 모두 2틱을 사용하며 해당 행동 후 목표 지점은 이동한다. 누르고 있어도 연속으로 낚지 않고, 원형 경계의 호수 밖 입력은 무시한다. 획득 시 splash, 희귀 어종이면 shine도 함께 재생한다. 호수는 기본 음악을 낮춰 유지하고, 음성 안내 중에도 탐색 물소리는 줄이지 않는다. 낚싯대 사용량은 성공 시에만 증가하며, 사용량이 증가할수록 5회 이후 파괴 확률이 10퍼센트씩 점진적으로 늘어난다.

| 물고기 | 기본 판매가 | 요리 용도 |
|---|---:|---|
| 정어리 / 고등어 / 배스 | 각 24골드 | 스튜 / 구이 / 튀김 |
| 잉어 / 메기 / 가자미 | 각 27골드 | 구이 / 스튜 / 튀김 |
| 연어 / 무지개송어 | 각 36골드 | 구이 / 스튜 |

### 상점과 요일 효과

마을의 상점을 선택한 뒤 Sell·Buy·Calendar를 고른다. 아이템에 포인터를 올려 가격과 보유량을 확인하고 선택하면 하나씩 거래한다. 작물 씨앗·비료·도구·일부 광물·나팔꽃 씨앗을 구매하고, 거래 가능한 작물·음식·물고기·광물을 판매한다. 목록은 스크롤 대신 페이지로 나눈다. Calendar는 다른 화면을 열지 않고 오늘의 효과만 읽는다.

| 요일 | 효과 |
|---|---|
| 월요일 | 광석 구매가 20% 할인 |
| 화요일 | 요리 판매가 20% 증가 |
| 수요일 | 물고기 판매가 20% 증가 |
| 목요일 | 작물 씨앗 구매가 20% 할인 |
| 금요일 | 광석 판매가 20% 증가 |
| 토요일 | 비료·곡괭이·낚싯대 구매가 20% 할인 |
| 일요일 | 거래 가능한 모든 품목 판매가 20% 증가 |

1일차는 월요일이다. 적용되는 배율마다 소수점을 버리며, 판매가 증가 음식 효과도 화면 가격과 지급액에 반영한다.

### Rowan과 튜토리얼 퀘스트

Rowan은 상점 옆에 있다. 선택하면 마을 화면을 유지한 채 대사를 듣는다. 채소를 제출할 때만 별도 선택 페이지를 열며, 시각화는 초상화와 대사를 겹쳐 표시한다. 호버 음성이 진행 중인 퀘스트 대사를 덮어쓰지 않고, 새 대화는 이전 대화를 교체한다.

첫 대화에서는 스튜와 같은 수확 효과를 가진 **Rowan's soup**를 받는다. F2에서 먹거나 상점에 판매한 뒤 돌아오면 작물 씨앗을 종류별로 하나씩 받는다. 수프의 기본 판매가는 100골드다. 다음 대화에서는 농사 안내와 채소 요청을 받는다. 제출 화면에서 보유 작물 하나를 선택하면 100골드를 받으며 양쪽 방향키로 취소할 수 있다. 선물·보상·진행 상태는 저장된다. 이후 조언과 최근 활동에 대한 반응도 Rowan의 음성으로 들려주며, 상점의 별도 조언 탭은 사용하지 않는다.

### 연구

집의 연구대에서 업그레이드를 확인하고 선택하면 골드와 재료를 소비한다. 목록은 한 행에 세 개씩 배치한다. 연구는 활동 시간을 사용하고 진행 상태도 저장하며 추후 다양하게 추가할 예정이다.

| 연구 | 재료 | 효과 |
|---|---|---|
| Seed recovery | 골드·구리 | 씨앗 회수 개선, 최대 2단계 |
| Farm expansion | 골드·돌 | 기본 2개에서 최대 6개로 밭 확장 |
| Mineral luck | 골드·철 | 광물 획득과 보너스 수량 개선, 최대 2단계 |

플레이 안내에는 정확한 확률 대신 연구 단계를 안내한다.

### 화초 기르기

상점에서 나팔꽃 씨앗을 150골드에 사고 집의 **Flower pot**을 선택해 심는다. 기본적으로는 골드 소모량이 많고 실제 이득이 적은 꾸미기 기능이며, 집의 작은 그림과 확대 화면에서 새싹·줄기·꽃·시듦 상태를 관찰할 수 있다. 상세 화면은 식물 위에 물주기와 화분 비우기 버튼을 둔다.

꽃이 핀 동안 특수 효과를 얻는다. 해당 부분은 숨겨진 효과이며, 나팔꽃의 경우 작물 수확량이 1씩 증가한다.

물주기를 고른 뒤 실제 화분 부분에 포인터를 합계 3초간 둔다. 클릭 없이 접촉 시간으로 완료를 판정한다. 매일 물을 주고 잠들면 새싹에서 줄기까지 이틀, 줄기에서 꽃까지 이틀이 걸린다. 꽃이 피면 줄기로 돌아가지 않고 꽃 상태를 유지하지만 시간이 지날수록 시들 가능성이 높아진다. 물을 주지 않은 날도 위험을 높인다. 시든 식물에는 물을 줄 수 없으며 화분을 비운 뒤 다시 심는다. 개화 보너스와 시듦 확률은 플레이 중 공개하지 않는다. 현재 기를 수 있는 화초는 나팔꽃이며 다른 씨앗 이미지는 추후 제작예정이다.

### 저장과 로드

F3를 0.8초 길게 누르면 새 파일에 저장한다. 누르고 있는 도중 **Game saved.**가 나오며, 손을 떼도 현재 화면을 유지한다. 짧게 누르면 저장 목록을 열고 슬롯을 선택해 불러온다.

`saves/`에는 최근 12개의 JSON 저장 파일만 유지하며 오래된 슬롯은 삭제한다. 골드·아이템·날짜·밭·연구·음식 효과·퀘스트·광산·낚시·화초 상태를 복원한다. 이전 형식은 기본값과 기능별 변환으로 보완한다. 장치 연결·카메라 보정·브라우저 음향 설정은 진행 저장과 별개다. 서버 메모리의 진행은 자동 영구 저장이 아니므로 종료 전에 저장이 필요하다.

## 시스템 구성

FastAPI 서버가 게임 상태를 보유하고 행동을 판정한다. 브라우저는 포인터·키 입력을 보내고 도트 행렬·공개 상태·음성·소리 이벤트를 받는다. USB·Bluetooth·마우스·키보드·카메라 입력은 공통 게임 입력 경로로 들어간다. 시각화 창은 공개 상태만 받으며 게임 명령을 보내지 않는다.

### 게임 기능별 코드

각 폴더의 README에는 화면·행동·상태·이벤트·설정·테스트를 정리한다. 대부분의 동작은 `feature.py`에 있고 농사는 관리·그리기·거래 코드를 추가로 분리한다.

| `game/` 아래 폴더 | 역할 |
|---|---|
| `home/`, `minimap/` | 집 시설, 미니맵 노드와 장소 선택 |
| `farming/`, `harvest/` | 밭 상태·심기·물·비료·성장·수확 |
| `cooking/`, `seafood/` | 요리법·재료 선택·경로·생선 요리 변형 |
| `mining/`, `fishing/` | 바위·낚시·도구 사용량·자원 가격 |
| `flowers/` | 화분 상호작용·일일 성장·개화 효과 |
| `inventory/`, `shop/` | 아이템 목록·페이지·거래 |
| `research/` | 업그레이드 비용·단계·밭 확장 |
| `village/`, `npc/` | 마을·튜토리얼·제출·요일 가격·대사·활동 반응 |

기능은 `engine/core/registry.py`에 등록하며 `game/__init__.py`에서 활성화할 기능을 정한다. 슬롯에 아이템과 그림을 제공하고 이벤트로 다른 활동에 반응한다. 기존 엔진 속성 이름은 저장 파일과 연결되므로 이름 변경이 저장 호환성을 깨뜨릴 수 있다.

### 브라우저, 패드와 손 추적

| 경로 | 역할 |
|---|---|
| `engine/web/game.html` | 시뮬레이터 페이지와 조작 UI |
| `engine/web/core/game.js` | 포인터 요청 큐·상태 출력·상세 모드·음성/소리 전달·시각화 갱신 |
| `engine/web/core/pages.js`, `game/<feature>/client.js` | 기능별 브라우저 문구와 연결 코드 |
| `engine/web/core/game-keys.js` | 기능 키·방향키·F3 길게 누르기 |
| `engine/web/core/game-audio.js`, `game-speech.js` | 음악·효과음·입체음향과 서버 음성 재생 |
| `engine/web/core/pad/hardware.mjs` | Web Serial USB 출력·패드 버튼·손 추적 WebSocket 연결 |
| `engine/web/core/pad/bluetooth-pad.mjs` | Dot Inc. SDK를 통한 Bluetooth 연결 |
| `engine/tracking/` | 카메라 인식·보정·WebSocket 서버 |

패드는 도트를 올리고 버튼 입력을 보내며, 손가락 좌표를 직접 감지하지 않는다. 카메라가 MediaPipe와 ArUco 마커를 이용해 손끝을 패드 좌표로 변환한다. 추적용 `opencv-python`, `mediapipe`, `numpy`, `websockets`는 게임 의존성과 별도로 프로젝트 가상환경에 설치한다. `python engine/tracking/tracking_server.py` 또는 Windows용 `.bat`로 실행하며 `tracking_test.py`는 미리보기용이다. `engine/config/tracking.json`에서 설정하고 기본 WebSocket 포트는 8765다. 좌표만 보내는 입력원은 F4를 선택 버튼으로 사용할 수 있다.

Bluetooth는 `engine/web/core/pad/vendor/`의 SDK 3.0.3과 의존 파일이 필요하다. 설치 옵션 `--with-pad` 또는 `python engine/launcher/prepare_pad.py`로 준비한다. USB에는 해당 SDK가 필요 없다. 대상 컴퓨터의 브라우저 지원과 장치 권한을 확인한다. HTML은 파일로 직접 열지 않고 서버로 접속하며, 웹 수정 후에는 강력 새로고침하고 시각화 창도 다시 연다.

### Visual Companion과 이미지

**Open visual display**로 읽기 전용 창을 열고 원래 게임 탭도 유지한다. 장소·선택·활동 진행·획득물·대사·화초 단계·시간대를 따라간다. 각 밭과 바위는 실제 게임 객체와 연결되며 인벤토리·상점 카드도 촉각 화면과 같은 페이지의 항목을 보여준다.

| `engine/web/spectator/` 아래 | 역할 |
|---|---|
| `standalone.html`, `boot.js` | 별도 창 진입과 시작 연결 |
| `display.js` | 현재 시각화에서 읽는 실행용 묶음 |
| `viewer.js`, `model.mjs`, `viewer.css` | 장면 그리기·상태의 배치 변환·UI 스타일 |
| `visual-assets.json` | 배경·시설·아이템·스프라이트 영역 등록 |
| `scene-objects.json` | 시설 위치·크기·순서 |
| `assets/` | 공통 이미지. 기능별 이미지는 `game/<feature>/assets/`에도 배치 |

배경·시설·아이템 등록을 분리해 기존 이미지를 재사용한다. 아직 시각화를 만들지 않은 화면은 도트 화면으로, 이미지 없는 아이템은 이름 카드로 대체한다. 신규 이미지를 추가할 때 기존 시트는 유지한다. **현재 저장소 규칙상 `display.js`를 수정하거나 재생성하면 안 된다.** 원본 파일과 합쳐지지 않은 수동 수정이 남아 있기 때문이다(후속 작업 F5). 이전 문서의 `build_display.py`로 다시 생성하라는 안내는 현재 적용하지 않는다.

### 오디오와 음성

`GameAudio`가 배경음악·작업음·성공음·단발음·합성 안내음을 재생한다. 공통 녹음은 `engine/web/audio/`, 기능별 녹음은 `game/<feature>/audio/`에 있다. `GameSpeech`는 서버에서 생성한 음성을 별도 게인으로 재생한다. TTS와 일반 비입체 효과음은 비입체로 유지한다.

| 음원 | 사용 상황 |
|---|---|
| `background-basic`, `background-minigame`, `background-shop` | 그룹별 음악. 같은 그룹에서는 다시 시작하지 않음 |
| `water`, `soil`, `crop`, `cut`, `cook` | 물·비료·수확·조리 작업음. 성공음과 독립 |
| `correct` | 목표 진행과 일반 획득 |
| `step`, `door`, `coin` | 이동·상점 입장·거래/유료 연구 |
| `pickaxe`, `break`, `destroy`, `shine` | 타격·바위 파괴·도구 파괴·희귀 획득 |
| `splash` | 물고기 획득. 희귀 획득 시 shine과 동시 시작 |
| `sleep` | 아침 전환 후에도 이어지는 1회 수면음 |
| 합성 안내음·목표 비콘 | 선택·실패·진행·선택적으로 켜는 방향 안내 |

작업 입체음향은 패드 중앙을 듣는 위치로 두고 포인터에 소리를 배치한다. 낚시는 포인터를 기준으로 숨겨진 목표의 소리를 배치한다. 목표 비콘은 농사·채광에서 남은 목표를 찾는 별도 안내이며 **Target cues**로 끌 수 있다. 상점 입장과 거래는 비입체, 이동은 누른 방향에 맞춘다. 현재 작업음은 `dry_gain: 0`으로 중앙 원음이 겹쳐 방향감이 약해지지 않게 한다. 작업 루프 도중 다시 눌러도 같은 녹음을 추가하지 않으며, 명시적 소리 이벤트가 있으면 겹치는 기존 피드백을 억제한다. 모든 소리를 입체화하는 설정은 아니다.

음성은 운영체제의 브라우저 음성 대신 고정된 영어 Piper 모델을 사용한다. 시스템은 `en_US-hfc_female-medium`, Rowan은 `en_US-hfc_male-medium`이며 내부 프로필 키는 여전히 `shopkeeper`다. 모델·WAV 캐시·보고서는 `.audio/voices/`, `.audio/cache/`, `.audio/reports/`에 저장한다. **Test guide**, **Test Rowan**, **Replay**, 음성 정지·켜기/끄기·속도·음량 조절을 제공한다. 음성 기본 음량은 85%이며 음악·효과음과 별도다.

행동 결과와 대화는 호버 문구보다 우선한다. 요청에 클라이언트·순서 정보를 넣어 늦은 응답이 최신 음성을 덮지 않게 한다. 새 NPC 대화는 이전 대화를 교체하고 일반 호버는 대화를 중단하지 않는다. 다른 창으로 이동하면 소리를 멈추고 늦은 응답을 버린다. 돌아오면 현재 음악과 호수 소리를 복구할 수 있지만 이전 대사를 다시 재생하지는 않는다. 음성 중에는 설정에 따라 음악과 일부 효과음을 낮추며 낚시 탐색음은 설정 음량을 유지한다.

## 향후 개발과 평가

추가 화초·펫·목축·요리·퀘스트·음악·제작을 확장할 계획이다. 공통 작업으로는 시각화 묶음과 원본의 차이 정리, 기능 간 직접 의존 축소가 남아 있다.

사용자 평가에서는 과제 성공률·수행 시간·오조작·촉각/음성 정보 이해·작업 부담을 기록한다. 구형 노트북의 포인터 지연, 카메라 보정과 가림, 도트 가독성, 발음, 입체음향은 실제 장비로 비교한다. 초기에는 시각장애·저시력 사용자 약 6~8명을 대상으로 심기·물주기·요리·이동·낚시·저장/로드 과제를 구성할 수 있다. 이는 평가 계획이며 실제 검증이나 사용자 연구를 완료했다는 뜻은 아니다.

## 기능 추가

1. `game/<name>/`에 `feature.py`(`register(reg)`에서 `engine/core/registry.py`를 통해 화면·행동·그리기·상태·이벤트를 선언하는 `Feature` 하위 클래스)와 이를 `Feature`로 내보내는 `__init__.py`를 만든다.
2. `game/__init__.py`의 `ENABLED`에 `<name>`을 추가한다.
3. 선택: `client.js`(화면 문구), `audio/`, `assets/`, `engine/config/game.json`의 설정 항목, `game/<name>/tests/`의 테스트, README.

2단계, 설정 값, 소리, 이미지, 그리고 `engine/`의 모든 변경은 승인이 필요하다. 예시는 [game/README.md](game/README.md), 규칙은 [AGENTS.md](AGENTS.md)에 있다.

## 테스트

```
.venv\Scripts\python.exe engine\tools\run_tests.py                   # 전체
.venv\Scripts\python.exe engine\tools\run_tests.py --feature fishing # 한 기능
```

macOS/Linux에서는 `.venv/bin/python engine/tools/run_tests.py`를 쓴다. Python과 Node 테스트(Node.js 20 이상), 브라우저 점검을 실행한다(`--no-browser`로 생략 가능. 브라우저 점검에는 `pip install -r engine/requirements-dev.txt`와 `python -m playwright install chromium`이 필요). 마지막 줄이 **All green.** 이어야 한다. 알려진 실패는 테스트 안에 표시되어 있고 이유와 함께 출력된다.
